# Smart-Invoice-System
Smart Invoice &amp; Billing System developed using Java OOP concepts, featuring GUI (Swing), MySQL database connectivity, and role-based user management


## 📦 External Libraries & Dependencies

This project requires the MySQL JDBC Driver to establish a database connection. 

* **MySQL Connector:** `mysql-connector-j-9.7.0.jar` (Isay aapne download karke apne IDE ke Build Path / Dependencies me add karna hai).
